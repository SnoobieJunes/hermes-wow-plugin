# Security

## Reporting

Report a vulnerability privately to Auston (GitHub [@SnoobieJunes](https://github.com/SnoobieJunes)) before opening a public issue. Do not attach SavedVariables files or name an account folder. Those files can identify a player.

## What this plugin does

It reads a World of Warcraft install and, only on an explicit tool call, writes an addon folder or `Inbox.lua`. It stores no credentials, holds no Discord token, and does not run shell commands or background processes of its own.

The game client, Blizzard services, and Hermes Agent itself are out of scope.
